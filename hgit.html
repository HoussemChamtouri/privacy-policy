Privacy Policy for H-Git

Effective Date: November 23, 2026  |  Package: com.hexsoft.hgit  |  Contact: hexsoft.support@gmail.com

1. Overview

H-Git is a native Android Git client developed by Hexsoft. Your privacy is fundamental to our design. H-Git operates directly on your device, contains no advertisements, no analytics SDKs, no crash-reporting trackers, and does not transmit your personal data to Hexsoft servers.

2. Information Stored Locally on Your Device

All data created or imported in H-Git is stored exclusively in your device's private app storage:

  • Git Repositories & Source Files: Cloned or initialized repositories reside locally on your device.
  • Credentials & SSH Keys: Your optional GitHub username, Personal Access Token (PAT), and repository passwords are encrypted at rest using the hardware-backed Android KeyStore (AES-256-GCM). SSH private keys are stored privately inside the app's sandboxed storage.
  • Git Profile & App Preferences: Your configured Git author name, commit email, and UI preferences are stored locally via Android SharedPreferences.

You can erase all saved credentials at any time via Settings → Clear Saved Credentials, or remove all local data by uninstalling the app.

3. User-Initiated Network Connections

H-Git only accesses the network when you explicitly initiate an action:

  • Git Remote Operations: When you clone, fetch, pull, or push, H-Git connects directly via HTTPS or SSH to the Git hosting server you configured (such as GitHub, GitLab, Bitbucket, or a self-hosted Git server).
  • Optional GitHub Token Test: If you tap Test Token in Settings, H-Git sends your Personal Access Token directly over HTTPS to https://api.github.com/user to verify authentication.
  • Optional Gravatar Avatars: If Use Gravatar images is enabled in Settings, H-Git sends an MD5 hash of commit author email addresses to https://www.gravatar.com to display author avatars. You may toggle this off at any time.

4. Data Sharing, Sale & Third-Party SDKs

  • Hexsoft does not collect, store, sell, rent, or share any user data with third parties.
  • H-Git contains no advertising networks, analytics libraries, or crash-reporting trackers.
  • H-Git explicitly removes the Android Advertising ID (AD_ID) permission.

5. Permissions Used

  • INTERNET & ACCESS_NETWORK_STATE: Used exclusively to connect to user-configured Git remotes, verify optional GitHub tokens, and fetch optional Gravatar avatars.

6. Children's Privacy

H-Git is a software development tool not directed at children under 13. Because H-Git collects no personal data, we do not knowingly collect personal information from children.

7. Changes to This Policy

Any updates to this Privacy Policy will be published on this page with an updated Effective Date.
